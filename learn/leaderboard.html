Leaderboard

Every game turns your score into points on the same scale, so players and schools can be compared across all twelve games. The board resets every week and every month.

How points work

100 points is a good run in any game, up to 150 for a great one. A school's total counts each player's points up to 3,000 a period, so one player alone cannot carry a school.
