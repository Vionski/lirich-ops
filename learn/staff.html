LIRICH LEARN

Twelve games, one unit of score

Every game here scores in the same thing — kilograms or tonnes diverted — so a single leaderboard can work across all of them later. All of them run in a browser, on a phone, a tablet or a school Chromebook, with no learner accounts, no login and no analytics in this beta. Stars, scores, collected cards and settings are stored only in that browser on that device. Dispatch is the odd one out — built for operators rather than classrooms, on Lirich's own operating facts.

This set is ready for a small, supervised board-off beta. Use the recommended routes below, let learners work without coaching for the first attempt, and record where they pause or guess. Stop and report any safety or factual concern before continuing.

THE BOARD Team standings A team is a label — a class, a crew, a floor. No accounts, nothing personal.
CHALLENGE BOARD Add ?challenge=week to any of the seven turn-based games and every player gets the identical board, so the score turns on skill alone. The four real-time games refuse — their scores depend partly on how fast the device draws frames.

Beta boundaries and follow-up work

BoundaryHow to handle it
SupervisionUse a teacher or Lirich facilitator for the first beta. The games teach decisions, not physical waste handling.
Indicative figuresCosts, emissions and operating numbers marked indicative are teaching values. Do not present them as quotations or measured Lirich performance.
Sorting rulesThe games now draw shared household sorting rules from one file. Lirich operations should still sign off the public wording before a wide launch.
Tipping-floor artSpot the Contaminant uses original drawn scenes until cleared, non-identifying Lirich photographs exist. The game is ready for them: follow the Spot photo brief in this folder, mark each hazard with the photo marking tool, and paste the result into spot-photos.js.
Shared boardThe leaderboard is off for this beta. Scores remain on the device; do not collect learner names.
OwnershipAssign one product owner to triage factual, safety, accessibility and technical feedback before each release.
